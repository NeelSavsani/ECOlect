## 📌 About The Project

ECOlect is an AI-powered e-waste management platform designed to simplify the collection, tracking, and recycling of electronic waste.

The platform connects users, recyclers, and collection centers to promote responsible e-waste disposal and environmental sustainability. ECOlect aims to reduce pollution caused by improper electronic waste disposal while encouraging digital waste management solutions.

---

## 🚀 Features

- ♻️ E-Waste Collection Management
- 🤖 AI-Powered Waste Classification
- 📍 Nearby Collection Center Locator
- 📊 Dashboard & Analytics
- 🔐 Secure User Authentication
- 📄 E-Certificate Generation
- 🌐 Responsive Web Portal
- 📦 Recycling & Tracking System
